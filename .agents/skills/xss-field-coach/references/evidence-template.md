# Minimal evidence record

- Exercise / authorized asset:
- Date (UTC), environment and relevant version:
- Delivery: reflected / stored / other:
- Processing path: server-rendered / DOM-based / mixed:
- Controlled source:
- Transformations in order:
- Exact sink and parser context:
- Existing defense and effective CSP:
- Harmless marker and minimal reproduction:
- Observed response / DOM / console result:
- Supported conclusion:
- What remains unproved:
- Root cause:
- Proposed repair:
- Regression result with the same marker and ordinary input:

For stored flows, show the write and the later read separately. Keep secrets and personal information out of screenshots and reports. Do not assign severity from a marker alone or describe simulation success as a live vulnerability.
