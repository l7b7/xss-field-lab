# Security reporting

This is an inert teaching model. Report a failure of its boundaries separately from a lesson suggestion or an incorrect answer check.

For a possible sandbox escape or exposure of private data, use GitHub's **Report a vulnerability** option when the repository owner has enabled private vulnerability reporting. If that option is unavailable, request a private contact route from the owner without posting exploit details publicly.

Include the affected file/commit, browser/environment, a minimal harmless reproduction, the observed behavior and the expected boundary. Do not attach credentials, cookies or another person's data. Avoid external requests and destructive proof actions.
