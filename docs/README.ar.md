# مختبر XSS — دليل مرتضى

نفس واجهة المختبر موجودة داخل `dist/`: عشرين تمرين موزعة على ثمان وحدات، تلميحات، إعادة ضبط، شرح بعد الحل، تتبّع البيانات، ودفتر ملاحظات.

## شغّله على كالي

من داخل مجلد المشروع:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

افتح `http://127.0.0.1:8000` بالمتصفح. حتى توقفه اضغط `Ctrl+C`. ما يحتاج تثبيت مكتبات أو خطوة build. افتحه عبر السيرفر المحلي حتى تشتغل JavaScript modules.

الواجهة نفسها تشتغل محلياً. GitHub يعرض كود المشروع والـREADME؛ عرض المختبر التفاعلي يحتاج سيرفر محلي أو استضافة. تسجيل دخول النسخة الخاصة الحالية تابع للاستضافة، ومو جزء من الملفات المنسوخة.

## سكيل Codex على كالي

المشروع يحتوي `.agents/skills/xss-field-coach`، وتگدر تشغّل Codex من مجلد المشروع وتكتب:

```text
$xss-field-coach
درّبني على XSS بالمختبر خطوة بخطوة. اشرح بالعراقي، خليني أتوقع النتيجة، وبعدها راجع الدليل وياي.
```

حتى تثبّتها لكل مشاريع المستخدم الحالي:

```bash
bash scripts/install-skill.sh
```

راح تنسخها إلى `~/.agents/skills/xss-field-coach` حسب مسار اكتشاف السكيلات الحالي في Codex. الأمر ما يحتاج sudo، وما يستبدل سكيل موجودة. إذا ما ظهرت، أعد تشغيل Codex. إذا نسختك تستخدم مسار مختلف، راجع توثيقها واستخدم `--skills-dir` وياه.

السكيل تنظّم طريقة شرح ومراجعة المساعد، وما تغيّر أوزان النموذج وما تضمن الاحتراف تلقائياً. تتدرّب وياك على تتبّع المصدر، التحويلات، مكان العرض، نوع السياق، اختيار الدفاع، وكتابة دليل صحيح.

## نمشي شلون؟

1. نبدي بعلامة نصية فريدة حتى نشوف الانعكاس.
2. نحدّد السياق: نص HTML، attribute، رابط، JavaScript، أو DOM.
3. نستخدم العلامة الخاملة المطلوبة بالتمرين، ونقارن المدخل بالناتج.
4. نقرا الـtrace ونشرح شنو ثبت، وشنو بعده ما ثبت.
5. نراجع الإصلاح ونعيد التحقق بنفس العلامة.

التقدّم والملاحظات تنحفظ بمتصفحك فقط. زر Reset يمسح حالة التمرين؛ Reset all يمسح الكل بعد التأكيد.

## حدود المختبر

ظهور علامة أو عنصر `mark` يثبت ملاحظة محددة بالمحاكاة، وما يثبت تنفيذ JavaScript. المدخلات ما تنفّذ سكربتات، وما توصل لمواقع خارجية. تمارين CSP تتوقّع سلوك حالات محددة، والـpreview نفسه يبقى بلا سكربتات دائماً.

خلي المستودع Private إذا تريد الكود يبقى خاص. GitHub Pages واستضافة الكود شيئين مختلفين من ناحية الوصول؛ لا تفعّل Pages على أساس أن خصوصية المستودع تحمي الموقع. المشروع ما يفعّل نشر Pages تلقائياً.

للتطوير والتحقق، تحتاج Node.js 22 أو أحدث:

```bash
npm test
npm run check
```
